# Changelog

## 1.0.0

- Initial release of Wikie for iOS 6.0 – 6.1.6 (ARMv7).
- Custom OpenZIM v5/v6 reader engine with ARMv7 unaligned-safe streaming.
- Support for Zstandard (zstd) and Deflate (zlib) decompressions.
- Fast binary title search with live prefix suggestions as you type.
- Built-in Wi-Fi drag-and-drop server and iTunes Documents file sharing.
- Native iOS 6 skeuomorphic UI with table index, search bar, and reader toolbars.
- Bookmarks and reading history.
