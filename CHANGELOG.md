# Changelog

## 1.0.5

- Kept iOS 6 compatibility while applying classic appearance settings on newer iOS versions.

## 1.0.4

- Fixed compilation of Wi-Fi upload request parsing for both supported architectures.

## 1.0.3

- Restored the glossy iOS 6 navigation, toolbar, buttons, and search bar on newer iOS versions.
- Used Helvetica Neue for app controls across both architectures.
- Refreshed the featured ZIM links and routed them through direct HTTP mirrors to avoid obsolete HTTPS redirects on iOS 6.
- Updated the Czech mini Wikipedia archive to the 2026-09 edition.

## 1.0.0

- Initial release of Wikie for iOS 6.0 – 6.1.6 (ARMv7).
- Custom OpenZIM v5/v6 reader engine with ARMv7 unaligned-safe streaming.
- Support for Zstandard (zstd) and Deflate (zlib) decompressions.
- Fast binary title search with live prefix suggestions as you type.
- Built-in Wi-Fi drag-and-drop server and iTunes Documents file sharing.
- Native iOS 6 skeuomorphic UI with table index, search bar, and reader toolbars.
- Bookmarks and reading history.
